# ngx-formbar

![NPM Downloads: Core](https://img.shields.io/npm/dw/@ngx-formbar/core?label=Downloads:%20Core)
![NPM Downloads: Reactive Forms](https://img.shields.io/npm/dw/@ngx-formbar/reactive-forms?label=Downloads:%20Reactive%20Forms)

A framework for generating forms from a declarative configuration.

The configuration can come from a server as JSON or directly from a TypeScript object. ngx-formbar stays as close to Angular as possible: you keep direct access to the form object, and the library builds and manages the form controls from your configuration.

## Documentation

For installation options, guides, examples and API reference, visit the full documentation at [docs.ngx-formbar.net](https://docs.ngx-formbar.net).
